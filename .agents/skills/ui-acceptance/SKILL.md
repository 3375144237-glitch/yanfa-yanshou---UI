# 验收已实现的 UI

以对应 Figma 版本、评论、注释、测量和已确认的实现依据为基线。用户只要求验收时只读检查产品代码；修改交给单独授权的开发任务。没有可运行的目标页面或对应设计时，说明该范围未验收。

1. 用相同平台、设备规格、系统设置、页面状态和内容原点比对。iOS/Android 可读已有 Appium 会话，鸿蒙用兼容且已验证的驱动或项目导出的统一快照，Web/H5 可直接采集网址。分别判断各端，不以一端结果代替另一端。
2. 需要量测时，在工具仓库运行 `python3 scripts/yanfa_review.py check --config <配置路径>`，配置见[接入规范](../../../docs/接入与快照规范.md)。检查 `review.json` 和截图证据；确认建议映射后复用，未确认的自动配对只记候选。未读到的设计说明、不可见元素及原生树未提供的属性不能记为通过。图像内容、遮挡、阴影、字体渲染、交互状态等结合运行证据核对。
3. 在任务回复中给出验收结论、实际覆盖的端/设备/状态和剩余差异。差异写清设计值、实际值与证据；只引用核实过的代码位置。用户需要表格时加 `--xlsx`，无需打开独立问题网页或上传设备截图到 Figma。
4. 同一基线用 `--previous <上轮/review.json>` 复验。仅在相同条件下可靠复测通过才结案；范围外、证据缺失或基线变化保留未复验。检查覆盖率只反映已声明属性，不是整页还原度分数。
